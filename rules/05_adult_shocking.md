# Регламент: Контент 18+ и шок-контент

## Цель
Не допускать публикацию сексуального, порнографического и натуралистичного шок-контента в тексте и изображениях, при этом корректно обрабатывать нейтральные медицинские и новостные контексты.

## Технические зависимости и контракт
- `vision_adult_score`: вероятность сексуального/ню-контента `0.0..1.0`.
- `vision_gore_score`: вероятность графического насилия/крови `0.0..1.0`.
- `adult_text_patterns`: словарь сексуализированной лексики и явных 18+ описаний.
- `gore_text_patterns`: словарь натуралистичных описаний травм/расчленения/крови.
- `ocr_result`: массив `{text, confidence}`.
- `context_classifier`: метка контекста `neutral|medical|news|fetish|pornographic|violent`.

Минимальный формат:
```json
{
  "vision_adult_score": 0.91,
  "vision_gore_score": 0.12,
  "context_classifier": "pornographic"
}
```

## Термины и определения
- **Нагота**: демонстрация интимных частей тела в явном виде.
- **Сексуализированный контент**: акцент на сексуальных действиях/возбуждении, даже без полной наготы.
- **Шок-контент**: графические сцены крови, тяжелых травм, расчленения и т.п.
- **Нейтральный контекст**: медицинское/новостное описание без натурализации и без цели шокировать.

## Нормализация входа
- Хранить `raw_text` и `normalized_text`.
- В `normalized_text`: lowercase, сжатие повторов, нормализация эвфемизмов/обфускаций для сексуальных терминов.
- OCR-текст проходит ту же нормализацию, при confidence < 0.65 добавляется техфлаг.

## Алгоритм проверки
1. Прогнать текст через `adult_text_patterns` и `gore_text_patterns`.
2. Для каждого изображения получить `vision_adult_score` и `vision_gore_score`.
3. Провести OCR и анализ текста на изображении.
4. Классифицировать контекст (`medical/news/neutral` vs `pornographic/violent`).
5. Пороговая оценка:
- `vision_adult_score >= 0.85` -> высокий риск 18+.
- `vision_gore_score >= 0.85` -> высокий риск шок-контента.
- `0.60..0.84` -> пограничный риск, отправка в `REVIEW`.
6. Выбрать решение по детерминированной таблице.

## Таблица решений (детерминированная)
- `REJECT`:
- `ADULT_NUDITY` при `vision_adult_score >= 0.85`.
- Или `ADULT_SEXUAL_TEXT` с явным описанием сексуальных действий.
- Или `SHOCK_GORE_IMAGE` при `vision_gore_score >= 0.85`.
- Или `SHOCK_GORE_TEXT` с натуралистичным описанием жестокости.
- `REVIEW`:
- Пограничный визуальный риск (`0.60..0.84`).
- Или смешанный контекст (медицинский/новостной), где авто-решение неуверенно.
- Или низкая уверенность OCR при подозрении на 18+/gore-текст в изображении.
- `APPROVE`:
- Нет reason-кодов 18+/шок.
- Есть нейтральный контекст без натурализации.

## Приоритеты и мультиразметка
- Формат: `primary_reason_code` + `secondary_reason_codes[]`.
- Приоритет:
1. `SHOCK_GORE_IMAGE`
2. `ADULT_NUDITY`
3. `SHOCK_GORE_TEXT`
4. `ADULT_SEXUAL_TEXT`
- Если в контенте одновременно сексуальный и шок-компонент, первичным выбирается более опасный визуальный риск.

## Reason codes
- `ADULT_NUDITY`: изображение содержит явную наготу/сексуализированную демонстрацию.
- `ADULT_SEXUAL_TEXT`: текст описывает сексуальные действия в явной форме.
- `SHOCK_GORE_IMAGE`: изображение содержит графическое насилие/кровь/тяжелые травмы.
- `SHOCK_GORE_TEXT`: текст содержит натуралистичные шок-описания насилия.

## Примеры
- `REJECT`: фото с явной наготой или порно-сцена.
- `REJECT`: "подробно описывает расчленение/кровавые детали".
- `REVIEW`: медицинская фотография после операции без ясной классификации.
- `APPROVE`: "было неприятно смотреть на бардак" (без шок-деталей).

## Edge cases
- Кормление грудью и образовательный медицинский контент анализируются в контексте и часто требуют `REVIEW`, не автоматический `REJECT`.
- Слово "секс" в нейтральном мета-обсуждении без описаний не всегда нарушение.
- "Кровь" в переносном/метафорическом смысле не считать `SHOCK_GORE_TEXT`.
- Художественные изображения без натуралистичных деталей могут переходить в `REVIEW`.

## Тестовая матрица
- T1: `vision_adult_score=0.9` -> `REJECT`, `ADULT_NUDITY`.
- T2: явное сексуальное описание в тексте -> `REJECT`, `ADULT_SEXUAL_TEXT`.
- T3: `vision_gore_score=0.88` -> `REJECT`, `SHOCK_GORE_IMAGE`.
- T4: натуралистичное описание травм -> `REJECT`, `SHOCK_GORE_TEXT`.
- T5: medical-context, score 0.72 -> `REVIEW`.
- T6: безопасный бытовой отзыв -> `APPROVE`.
- T7: OCR confidence < 0.65 при подозрительном изображении -> `REVIEW`.
- T8: FP-контроль: "ужасный сервис" (без шок-содержания) -> `APPROVE`.
